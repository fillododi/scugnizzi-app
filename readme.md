# App per Scugnizzi

## Front-end: React native con EXPO
per avviare:
```
    cd frontend
    npm run android
    npm run ios (o su mac oppure installare la expo app)
    npm run web
```

## Back-end: Express js
per avviare:
```
    cd backend
    npm start
```

## Database: MySQL
nella cartella database si terranno tutti gli script e file di configurazione per il database
